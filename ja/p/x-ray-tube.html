X 線管：連続 X 線と特性 X 線

速い電子が金属のターゲットに当たって急に減速すると、連続 X 線（制動放射）が出ます。いちばんエネルギーの大きい光子は、電子が運動エネルギーをすべて一度に渡したときのものなので、最短波長があります。電子がターゲットの原子の内側の電子をはじき出すと、外側の電子がそこを埋めるときに決まった波長の鋭いピークが出ます。これを特性 X 線といい、ターゲットの物質で決まります。

物理基礎 · 物理（原子） シミュレーション 日本語

使う公式

eV=hf_max=(hc/(λ_min)), λ_min(nm)≈1240/V

学習のポイント

  • 連続 X 線は電子の減速から生じる（制動放射）
  • 最短波長は加速電圧だけで決まり、ターゲットには関係しない
  • 特性 X 線の位置はターゲットで決まり、電圧には関係しない
  • 電圧がしきい値をこえないと特性 X 線は出ない
